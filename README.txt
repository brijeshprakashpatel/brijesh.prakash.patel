BRIJESH PORTFOLIO WEBSITE
=========================

This is a professional portfolio website for Germany IT / Software Developer job applications.

Files:
- index.html
- style.css
- script.js
- assets/Brijesh_Germany_IT_Resume_Professional.docx

How to edit:
1. Open index.html.
2. Replace:
   - your.email@example.com
   - linkedin.com/in/your-profile
   - github.com/your-profile
   - Brijesh surname if needed
3. Replace the resume file in assets folder if you have a newer version.
4. Upload all files to GitHub Pages, Netlify, Vercel, or your own hosting.

GitHub Pages setup:
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to Settings > Pages.
4. Select Branch: main and Folder: /root.
5. Save.
6. Your portfolio URL will be generated by GitHub.

Recommended GitHub repo name:
brijesh-portfolio

Resume download path:
assets/Brijesh_Germany_IT_Resume_Professional.docx
